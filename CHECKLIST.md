# CHECKLIST.md — ревью кода бота

Чек-лист для детерминированного гейта самопереписывания (DESIGN §8.3) и для
человеческого/модельного ревью diff кандидата. Проверяйте только то, что реально
меняется в diff; отсутствие нарушения подтверждайте по коду, а не по описанию.

## 1. Границы и защищённые пути

- [ ] Кандидат не трогает `CHARTER.md`, `CHECKLIST.md`, `packages/guard/**`,
      `packages/evolve/**` (гейт самопереписывания), `packages/tools-exec/**`
      (песочница исполнения), `deploy/**`, `scripts/**`, тесты характера и
      список защищённых путей.
- [ ] Нет попыток обойти `guard.isProtected`: symlink, `..`, смена регистра,
      переименование защищённого файла, правка через новый путь.
- [ ] Изменения не расширяют права бота: публикация, push в remote, смена
      видимости репозитория, выдача доступа гостям, отключение guard.

## 2. Секреты и песочница

- [ ] В коде, тестах, логах и ошибках нет токена Telegram, ключа DeepSeek,
      содержимого `.env*` и путей к ним.
- [ ] Новый код не запускает команды на хосте: исполнение идёт только через
      `packages/tools-exec` (bwrap) или гейт (`npm test` в bwrap).
- [ ] Не ослаблены монтирования песочницы: HOME пустой, `XDG_RUNTIME_DIR` не
      виден, живой `node_modules` только на чтение, сеть закрыта.
- [ ] Новые дочерние процессы не наследуют ключи и не получают лишние корни.

## 3. Зависимости и сборка

- [ ] `package.json` и `package-lock.json` не меняются: зависимости ставятся
      только через завод.
- [ ] Нет новых внешних зависимостей, install-скриптов и обращений в сеть.
- [ ] `npm test` (tsc + vitest) проходит; новые тесты падают без правки и не
      пишут в отслеживаемые файлы.
- [ ] Версии `typescript`, `@types/node` и пакетов харнесса остаются точными.

## 4. Самопереписывание и адопция

- [ ] `self_change` создаёт worktree от `live`; правки идут только в кандидате,
      `live` остаётся чистым и на своей ветке.
- [ ] Гейт запускается до карточки: защищённые пути, зависимости, тесты, ревью.
- [ ] `adopt.json` пишется только по нажатию «Принять» и содержит sha коммита.
- [ ] `scripts/adopt.sh` переводит ветку `live` на sha (`checkout -B live`, без
      detached HEAD), удаляет `adopt.json` и не теряет stable-тег.
- [ ] Предохранитель откатывает live на `stable` после трёх падений за 120 с и
      не откатывает живой healthy-процесс.
- [ ] Выход 42 не попал в `RestartPreventExitStatus` и не стал успешным кодом.

## 5. Поведение и честность

- [ ] Ошибки возвращаются текстом с причиной; «готово» не выдаётся без
      пройденной проверки.
- [ ] Отмена, таймауты и недоступность модели не оставляют процесс в
      полу-принятом состоянии.
- [ ] Модель не получает инструментов, которых у неё не должно быть; гостю
      по-прежнему не видны read/edit/exec и эволюция.
- [ ] Промпты и рабочие правила не ослабляют CHARTER.
